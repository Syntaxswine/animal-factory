# Hospital equipment collection 01

Six transparent PNG sprites generated with built-in image_gen. Style reference: `dist/assets/environment/facility/medical-exam-table.png`. Originals retain generated alpha without processing.

Files: `dist/assets/environment/hospital/`. Preview: `dist/tactics/hospital-art.html`.

## Intended map footprints

| Sprite | Occupancy |
| --- | --- |
| IV stand (`iv-stand.png`) | 1×1 |
| Bedside monitor (`bedside-monitor.png`) | 1×1 |
| Instrument trolley (`instrument-trolley.png`) | 1×1 |
| Hospital bed (`hospital-bed.png`) | 1×2 |
| Wheeled stretcher (`wheeled-stretcher.png`) | 1×2 |
| Scrub sink counter (`scrub-sink.png`) | 1×2 |

1×2 means one tile wide, two tiles long; the long axis in the art runs lower-left to upper-right. These are art assets with intended occupancy, not runtime prop definitions. World scale, placement anchors, collisions and treatment interactions still need integration. Square source canvases are not square world footprints. Detail and 96 px gallery views fit art for inspection and are not world-scale previews.
