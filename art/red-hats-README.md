# Red Hats faction

Six standing, unarmed uniform variants: horse, goat, donkey, sheep, cow, hen. The existing pig foreman defines the uniform. Red peaked caps and red armbands identify the faction.

Created with the built-in image generation tool. Exact prompts and the hen foot refinement are saved in `red-hats-sources.json`. Full resolution originals: `art/source/red-hats/`. Runtime sprites: `dist/assets/characters/red-hats/<species>-idle.png`.

Runtime frames are 256 × 256 RGBA, visible height 236 px, ground anchor [128,244]. Export using `tools/prepare-red-hats.ps1`; alpha and aspect ratio are preserved. The preview is `dist/tactics/red-hats.html`, linked from the character gallery. This art set does not yet assign faction membership in gameplay or provide armed/moving/crouched variants.
