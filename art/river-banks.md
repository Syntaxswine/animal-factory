# Modular river banks

Preview: `dist/tactics/river-bank-art.html`. Renderer: `river-banks.js`.

The saved `dist/assets/environment/foliage/river-banks-atlas.png` is a 512×512 transparent overlay atlas with sixteen 128×128 cells. Index is row-major, using connection bits north=1, east=2, south=4, west=8. Index 0 is an isolated pool, not dry land. Draw water beneath each overlay, at the same phase and orientation as its neighbors; do not rotate the animated water with bank orientation.

Banks are generated by the canvas renderer from the existing grass texture. Shared ports use a width of 0.47 tiles. Adjacent two-port bends use quarter-circle centerlines. Mud bands and small interior contour variation are fixed; only the water moves. Variation and its derivative vanish at boundaries. Compatible tile edges match all four RGBA channels. Dry land must use the same periodic grass texture and edge sampling as the preview.

The preview includes meander, junction and isolated-pool arrangements, animation pause, a tile grid, the complete tile set and atlas export. The meander ends deliberately demonstrate end caps.

Validation: exhaustive compatible-edge tests for all sixteen patterns, open/closed port checks, water loop tests, browser layout/animation/grid/download checks and visual review. This is a reusable rendering module and exported bank set, not map editor or gameplay integration.
